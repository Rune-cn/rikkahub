# 07 · UI 交互与代码约定

## 1. 设置搜索（经历多次迭代，按现状改，别回退）

- 入口完全并入顶栏：**点顶部「设置」标题展开**，展开后顶栏整条变成圆角搜索输入框（AnimatedContent 淡入淡出 + 位移动画）。
- 交互约定：
  - 键盘右下角是「搜索」键：按下 = 完成输入，**只收起键盘**，结果保留（`SettingSearchField` 里 `onSearch -> keyboardController.hide()`）。
  - 彻底收起 = 点输入框右侧 **↓** 按钮（`collapseSearch()`：清空关键词 + 收起 + 隐藏键盘）。
  - **不要再把键盘「搜索」键绑成"收起"**（会造成"一搜就没了"的假故障）。
  - 收起态不显示任何搜索痕迹（无胶囊、无图标），只有「设置」标题两个字可点。
  - 展开后自动聚焦弹键盘：`LaunchedEffect(searchExpanded)` 里 `delay(90)` 再 `requestFocus()`（等顶栏动画切换完成）。
- 结果：按页面分组的原生 `CardGroup` 卡片组，组内项 = CardGroupIcon(圆底类型图标) + 命中词高亮标题（`highlightKeyword`）。
- 相关代码：`ui/pages/setting/SettingSearchIndex.kt`（SettingSearchField/SettingSearchResults/searchSettingItems/SETTING_SEARCH_ITEMS）、`SettingPage.kt`（searchExpanded 状态 + topBar）。
- 新增设置项时往 `SETTING_SEARCH_ITEMS` 加一行（带中文关键词），否则搜不到。

## 2. 图标使用规则（踩过坑）

- HugeIcons 图标**用前必须 grep 验证**：`grep -rn "HugeIcons.XXX" app/src/main/java | head`，或确认在项目已 import 的图标清单里。部分图标（如 MoreHorizontal01/Pencil01）不存在，直接编译失败。
  - 注意：图标是 `me.rerere.hugeicons.stroke.*` 下的扩展属性，**用哪个图标就要 import 哪个**（`import me.rerere.hugeicons.stroke.Refresh` 才能写 `HugeIcons.Refresh`）；别处用过不代表当前文件能用，报 `Unresolved reference` 时先补 import（2026-10-31 构建踩过）。
- 列表入口项统一用 `CardGroupIcon(icon, containerColor, contentColor)`（圆底圆圈样式）；不要用裸 `Icon`（观感不一致，用户明确要求过圆圈包裹）。
- UI 代码**禁用 emoji**（User 要求）；README/发布说明可保留上游 emoji 风格。

## 3. Compose 约定

- `remember` / `stringResource` / 分组计算放函数体，`LazyColumn` 内容里只放 `item`/`items`。
- 闭包（launcher/lambda）用到的变量（context/settingsStore/scope）必须定义在其之前。
- 列表项用 CardGroup 的 item 或自定义 Row/Column + Surface；⚠️ 不要用 ListItem / SwipeToDismissBox（本仓库 material3 1.5.0-beta02 兼容问题，滑动删除改走 ⋮ 菜单）。
- 设置写入一律 `settingsStore.update { it.copy(...) }`（内存权威），禁止整份快照写回。

## 4. 字符串

- 新增字符串必须**三语同步**：`values/strings.xml`（英文）、`values-zh/strings.xml`（简中）、`values-zh-rTW/strings.xml`（繁中，缺了会回退英文，但尽量补）。
- 加之前查重：`grep -oP 'name="[^"]+"' <file> | sort | uniq -d`（重复会让资源打包失败）。

## 5. 页面导航

- `RouteActivity.kt`：`sealed interface Screen : NavKey` 里加 `@Serializable data object Xxx : Screen` → `composable<Screen.Xxx> { XxxPage() }` 注册。
- 新页面放对应功能目录（setting / extensions / log / workflow / …）；BackButton 无 onClick 参数（总是 popBackStack）。

## 6. 运行日志约定

- 关键操作/异常写入 `RunLog.log(tag, msg, level)`（utils/RunLog.kt，进程内环形）。
- 排查类功能优先留运行日志，不要只打 Logcat（用户在设备上看不到 Logcat）。

## 7. 链接点击约定（2026-10-31 新增）

- 对话内所有链接（正文 markdown / 引用角标 / 引用列表 / reasoning / 翻译 / 压缩检查点 / 搜索结果卡片与图片）点击后**一律弹 `LinkActionSheet`**（浏览器打开 / 内嵌打开 / 分享），不再直接跳浏览器。组件见 `ui/components/ui/LinkActionSheet.kt`，接入点清单见 02-11。
- 新增链接渲染入口时：给对应 `MarkdownBlock` 透传 `onLinkClick`（`MarkdownBlock` 本身已支持该参数）；不要在组件里自己调 `context.openUrl`。
- 非对话内链接（设置页/关于页/捐赠页等）保持原行为（`context.openUrl` 直接打开）。
