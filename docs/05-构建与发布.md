# 05 · 构建与发布

## 1. Flavor 与产物路径（上游 3.x 引入）

- `app/build.gradle.kts`：`flavorDimensions "distribution"`，flavor：`github`（默认，IS_PLAY_STORE=false）、`play`。
- 构建命令（Actions 用）：`./gradlew assembleGithubRelease`，产物在
  `app/build/outputs/apk/github/release/`（含 ABI split 与 universal，`app-github-arm64-v8a-release.apk` 等）+ `mapping.txt`。
- 下载表 / README 里的 APK 名必须是 `app-github-arm64-v8a-release.apk`。

## 2. 版本号规则（app/build.gradle.kts 顶部）

```kotlin
val appVersion = "3.0.0"        // 应用版本，每次发版手动改（用户要求才升）
val appVersionCode = 193        // versionCode，必须单调递增
val versionWithSha = (findProperty("versionWithSha") as String?)?.toBooleanStrictOrNull() ?: true
// versionName = versionWithSha ? "3.0.0-<sha>" : "3.0.0"
```

- 升级判断（UpdateChecker）：readme 见 02-9，比较用 versionName 去掉 `-<sha>` 后的版本号。
- 正式版（stable）：构建时传 `-PversionWithSha=false`，tag 为纯版本号（如 `3.0.0`）。

## 3. GitHub Actions（.github/workflows/daily-build.yml）

- 触发：push master / 定时 / workflow_dispatch（`release_type`: nightly 或 stable）。
- 步骤：签入（含子模块）→ JDK(JetBrains Runtime 21) → pnpm 安装 web-ui 依赖 → 解密 keystore → `assembleGithubRelease` → 计算版本 → 发布到固定 tag（nightly 或版本号）。
- 发布附件：`app/build/outputs/apk/github/release/*.apk` + `mapping.txt`。
- **交付链接（用户要求，每次回复必附）**：nightly 最新版
  `https://github.com/Rune-cn/rikkahub/releases/download/nightly/app-github-arm64-v8a-release.apk`
- **手动触发**（PAT 或 GitHub 页面）：
  ```bash
  curl -s -X POST -H "Authorization: token $TOKEN" -H "Accept: application/vnd.github+json" \
    "https://api.github.com/repos/Rune-cn/rikkahub/actions/workflows/daily-build.yml/dispatches" \
    -d '{"ref":"master","inputs":{"release_type":"nightly"}}'   # 或 "stable"
  ```
- 构建状态：`GET /repos/Rune-cn/rikkahub/actions/runs?per_page=1`；失败下载 logs zip 后 `grep "e: file"` 查编译错误。

## 4. 历史坑（改构建时注意）

- 字符串重复定义会让 `packageReleaseResources` 失败（加 <string> 前先查重，保留第一个）。
- 图标（HugeIcons.XXX）用前必须 grep 项目里是否已 import/使用（部分图标不存在会编译失败）。
- R8：上游 3.x 对 JLatexMath/SnakeYAML 等加了 keep 规则，**不要整库放开 keep**（会回到 40MB+ 时代）。
- 本 fork 同步后 APK 约 15MB（arm64 split + R8）。

## 5. 运行日志 / 崩溃排查

- `utils/RunLog.kt`（内存环形 1000 条）+ `ui/pages/log/RunLogPage.kt`（运行日志页：刷新/清空/复制全部/点行复制）。
- 入口：设置 → 关于 →「运行日志」。崩溃与搜索操作自动写入（见 02-其他）。
