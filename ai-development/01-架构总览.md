# 01 · 架构总览

## 1. 模块划分

| 模块 | 内容 | 说明 |
|---|---|---|
| `app` | Android 主模块（UI/聊天/设置/数据层/服务） | 主要修改都在这里 |
| `ai` (`me.rerere.ai`) | Agent 核心：`agent/`(AgentLoop/Retry)、`provider/`、`ui/UIMessage` | 上游 3.x 把生成循环从 app 移到了这里 |
| `workspace` | proot / SSH 工作区（含 jniLibs libproot_*.so） | 上游新增远程 SSH 工作区 |
| `web-ui` | 内嵌 Web 前端（编译进 APK，`buildWebUi` 任务） | 修改后构建较慢 |

依赖注入：Koin（`app/.../di/` 下 AppModule/RepositoryModule/DataSourceModule 等）。

## 2. 上游 3.x 关键重构（对后续开发影响最大）

### 2.1 GenerationLoop 已删除 ❗
- 旧路径 `app/.../data/ai/GenerationLoop.kt` 已不存在（上游删除）。
- 新架构：`ai/src/main/java/me/rerere/ai/agent/` → `Agent.kt` / `AgentLoop.kt` / `Retry.kt`。
- app 侧入口：`app/.../data/ai/ChatRequestFactory.kt`（构造请求）+ ChatService 的 `runTurn(session)` 跑循环。
- **任何旧代码引用 `GenerationLoop` / `GenerationChunk` 的地方都必须改，否则编译失败**（本 fork 已把子 Agent、工作流全部适配，见 04）。

### 2.2 PreferencesStore 已拆分 ❗
- 旧版 Settings 数据类在 `PreferencesStore.kt` 里；现在：
  - `data/datastore/Settings.kt`：Settings 数据类 + NetworkSetting + 各类小模型（含 fork 新增字段）。
  - `data/datastore/SettingsFields.kt`：**SETTINGS_FIELDS 注册表**（新增 Settings 字段必须在这里注册，读/写/变更检测都走它）。
  - `data/datastore/PreferencesStore.kt`：SettingsStore 类（`update(fn)` 写入、`awaitLoaded()`、`settingsFlow`）。
- fork 已注册的字段：`toolAutoAllowSetting`、`subAgentSetting`、`enableSubAgent`、`chatDrafts`、`workflows` 及 NetworkSetting 的重试字段。

### 2.3 productFlavors（github / play）
- `app/build.gradle.kts`：`flavorDimensions += "distribution"`，默认 `github`，另有 `play`（IS_PLAY_STORE）。
- **APK 产物路径变为 `app/build/outputs/apk/github/release/`**，Actions 与 README 下载表都已按此更新。
- 构建命令：`./gradlew assembleGithubRelease`（不是 assembleRelease）。

### 2.4 会话模型（ConversationSession）
- ChatService 以 `ConversationSessionManager` 为权威（内存 + 落库分离）：`session.update{}` 改内存、`session.flush()` 落库。
- 旧 fork 的 `updateConversation()`/`saveConversation()`/`handleMessageComplete()` 均已移除，调用方须改用 session API。

## 3. 包名与命名空间

- 应用：`me.rerere.rikkahub`（namespace），`applicationId = app.ai.rune`。
- UI 页面在 `app/.../ui/pages/` 下按功能分组（setting/extends/chat/assistant/...）。
